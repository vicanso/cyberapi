# Query、路径参数和请求头的类型

状态：已完成（2026-11-01）。数据模型编号 23。

只看接口的人用已经有的在线接口文档（`GET /v1/docs/<project-id>`）。这次补上 Query、路径参数和请求头的类型、必填、format 和枚举。不做阅读模式和调用模式的切换。

## 留下什么

导入 OpenAPI 3 或 Swagger 2 时，和名字、说明一起留在对应的参数行上。阅读的人不填、也不改。

| 项 | 从哪里读 | 怎么留 |
|---|---|---|
| 类型 | OpenAPI 3 的 `schema.type`；Swagger 2 的参数自己的 `type` | 见下一节的写法 |
| 必填 | 参数的 `required` | 布尔。文档写了就照写，没写时路径参数算必填，Query 和请求头不算 |
| format | `schema.format`；Swagger 2 的参数自己的 `format`。参数自己没有、但是数组时，用元素的 `format` | 原文，如 `date-time`、`int64`、`uuid` |
| 枚举 | `schema.enum`；Swagger 2 的参数自己的 `enum` | 值的列表。字符串用原文，数字和布尔用 JSON 写法 |

OpenAPI 3 的 `schema` 和 Swagger 2 的参数字段都要认。`$ref` 仍走现在的解析。

类型的写法，一行，不展开：

- 标量：`string`、`integer`、`number`、`boolean`。
- 数组：`array`，元素有类型时写成 `array<string>`、`array<object>`。元素仍是数组时写成 `array<array>`，不再往下拆。
- 对象：`object`。里面的字段不铺出来。请求体和响应体的字段表保持现在的样子。
- 没有单一 `type`、但是有 `oneOf`、`anyOf` 或 `allOf` 时，类型列写 `oneOf`、`anyOf` 或 `allOf`，不展开。有 `type` 时以 `type` 为准。

留在这些行上：

- Query：`HttpRequest.query`。
- 请求头：`HttpRequest.headers`。
- 路径参数：`HttpRequest.variables` 里、地址上的那几行（`in: path`）。同表里其他的接口变量不填这四项。

没记录过的行：类型、format、枚举为空，必填也没有记录。不要把这种空当成「非必填」。

表单字段、multipart 文件行、Cookie 参数这次不读、不写、不显示。Postman 等其他导入也不填这四项。

保存进项目的请求多了这四项。`cyberapi_core::version::MODEL` 是 23。

## 哪里显示

两处都只读。参数编辑行不加这四格，不能手改。

**说明标签。** 路径参数、Query、请求头那一行，在现在的名字、位置、说明旁边显示这四项。没记录的格子空着。表单和文件行保持现在的样子。说明文字仍在参数列表里改。

**在线接口文档。** 参数表加上 Type、Required、Format、Enum。这一页的栏名仍是英文。必填有记录时写 `required` 或 `optional`，没记录时空着。枚举多个值用 ` | ` 连起来。请求体 Schema、响应体 Schema 的表不改。

## 同步和再次导入

匹配方式和现在一样。参数值不覆盖。开着还是关着，也不因这四项而改。

**从来源同步。** 这四项跟文档走，和说明、开关一样。文档里空了，这边也清掉。文档里已经没有的 Query、请求头和路径参数继续删掉，包括读者自己加的。文档里还有的行，值留下。说明文字仍按 [从来源同步](./SOURCE_zh.md) 现在的规则，空说明也会清掉。

**手动「更新已有的」。** 这四项也跟导入的文档走，空了就清掉。说明文字不改成这套：导入没写的说明仍留下，导入写了的才换上。值，以及开着还是关着，仍留下。导入里没有的参数仍按 [导入](./IMPORT_zh.md) 现在的规则去掉。

**只添加新的。** 对得上的接口保持原样，这四项也不动。

结果没有变化时不写入，修订号也不增加。

## 导出

导出 OpenAPI 时，这四项有记录的写回参数的 `schema`（必填写在参数的 `required` 上）。

四项都没有记录的行，仍按现在的方式导出：路径参数是必填的 `string`；Query 和请求头非必填，类型从示例值猜。

Postman 导出这次不写这四项。

## 入口

在线文档只存在于服务器上的项目，地址仍是 `GET /v1/docs/<project-id>`。本机项目没有这个地址，不出现入口。

- 网页版：首页卡片的菜单里加「在线接口文档」。查看者也看得到。和树里那一项做同一件事：打开页面，并把地址复制到剪贴板。
- 桌面版：首页卡片不加。服务器项目仍用树标题栏 **⋯** 里已有的「在线接口文档」。

## 不做

- 应用里的阅读模式 / 调用模式切换。
- 在参数行里手改这四项。
- 把数组或对象参数展开成嵌套字段表。
- 表单字段和 Cookie 参数的类型。
- 改请求体 Schema、响应体 Schema 的展示。
- 改说明文字在手动导入和来源同步上已有的差别。
