# Cyber API 功能说明

桌面版和网页版的功能。只有其中一端才有的会写明。返回 [README](../README_zh.md)。

较长的三篇：[检查与运行](./CHECKS_zh.md)、[导入与导出](./IMPORT_zh.md)、[从来源同步](./SOURCE_zh.md)。桌面版界面见[图集](./GALLERY_zh.md)。

斜体版本号表示该行为在对应正式版发布前只在 nightly 里。

## 原生、快

- 支持 macOS、Windows、Linux，由 GPUI 在 GPU 上绘制。几千个接口的项目也是立即打开。
- 浅色、深色主题，中文、英文界面，字号和自动换行可调。
- 桌面版窗口在每块屏幕上都按上次离开时的位置打开。

## 项目、目录和接口

- 按名称或拼音搜索。拖动调整顺序，创建副本，移动到目录，或复制接口配置。
- 在项目或目录内查找与批量替换（地址、Query、请求头、请求体）。先预览匹配项再替换，10 秒内可在通知里撤销。
- 常用接口可以置顶（⌘/Ctrl-1…9），显示在标题栏，不再重复出现在下方的标签栏。点开时树里也选中它。
- 打开过的未置顶接口在请求和响应上方留成标签，最多 16 个。切回来时编辑内容、响应和还在进行的请求都还在。用关闭按钮、鼠标中键或 ⌘/Ctrl-W 关闭（右键可关闭其他或全部）。Ctrl-Tab / Ctrl-Shift-Tab 切换。下次打开项目时标签还在。可在设置的“编辑器”里关掉这一栏（*0.3.1*）；标题栏的置顶始终显示。
- 桌面版可以从标签或置顶接口的右键菜单**在新窗口打开**（*0.4.1*）：请求和响应左右并排，标题栏有自己的环境切换器，不必改主窗口的环境。主窗口的标签还在，点开时说明在另一个窗口里。关掉那个窗口（或 ⌘W）就移回来。关掉标签或离开项目时窗口一起关掉。
- **新建临时请求**（项目菜单或命令面板）另开一个标签，用这个项目的变量和环境，留在你自己的设置里，重启后还在。关掉标签就丢掉。能编辑项目时，**保存到项目…**选一个目录，它才成为那里的接口（*0.3.1*）。
- 首页的项目可以分组。
- 右键可以把接口或目录复制、移动到其他项目：先选项目再选目录。请求的全部内容和目录设置都带过去，响应历史不带。完成后列出那个项目里没有的变量（*0.4.1*）。
- 删除后 10 秒内可以在通知里撤销，放回原处，内容和置顶都在。被删接口的响应历史不恢复（*0.4.1*）。
- ⌘/Ctrl-Enter 发送，⌘/Ctrl-N 新建接口，⌘/Ctrl-F 搜索，⌘/Ctrl-L 跳到地址栏。方向键在树里移动。Delete 和 ⌘/Ctrl-D 删除、复制。快捷键一览列出全部快捷键。
- 在任何页面按 ⌘/Ctrl-K 打开命令面板：查找任意项目里的接口（名称、路径、目录、方法，也支持拼音）并打开，打开项目，切换环境，或执行命令（新建接口、导入、运行、最近发送、设置）。

## 请求

- Query、请求头，以及 JSON、表单、multipart、XML、纯文本请求体。写在地址栏里的查询参数会移到 Query 表。任何键值列表都能切换成文本批量编辑。
- 地址里有 `:param` 或 `{param}` 时，Query 上方出现路径参数。发送和生成代码时替换进 URL，并与 OpenAPI 的 `in: path` 参数和 Postman 的 URL 变量一起导入、导出。
- 路径参数、Query、请求头、表单请求体和目录变量的每一行都可以写说明（*0.4.1*）。切换文本批量编辑时保留。OpenAPI、Postman、Insomnia 会带进来，Postman、OpenAPI 和 MCP 会带出去。后来再次导入、或从来源同步时，空的说明怎么处理见[导入](./IMPORT_zh.md)和[从来源同步](./SOURCE_zh.md)。
- OpenAPI 和 Swagger 会留下路径参数、Query 和请求头的类型、是否必填、format 和枚举（*0.4.1*）。“说明”和在线接口文档只读显示。空着表示没有记录过，不是非必填。后来再次导入或从来源同步时这四项怎么处理，见[导入](./IMPORT_zh.md)和[从来源同步](./SOURCE_zh.md)。
- 认证可以写在接口上，也可以继承所在目录或项目：Basic、Bearer、放在请求头或查询参数里的 API Key、Digest，以及 OAuth 2.0（客户端凭据或密码）。值可以用模板函数。服务器要求时可以一并发送 audience 和 resource。令牌像 Cookie 一样存在你这里，不进项目、不同步、不进备份；过期或接口回答 401 时重新申请，有刷新令牌时先用它。客户端用 Basic 认证头，或放在请求体里。
- 桌面版的 OAuth 2.0 还可以是授权码 + PKCE（*0.3.1*）。**授权**打开系统浏览器，在 `127.0.0.1` 上接收回调，端口默认随机，也可以指定。网页版可以保存这套设置，并说明这一步只在桌面版进行。运行、命令行和 AI 助手不会打开浏览器，没有令牌时说明先在桌面版授权。
- 目录可以设置请求头，目录里的接口都会带上。
- 可设置超时、HTTP/1.1 或 HTTP/2、是否跟随重定向，以及是否接受自签名证书。单个接口可以在自己的“设置”标签里另设其中任意几项。
- 桌面版的请求可以经过 HTTP 或 SOCKS5 代理（在设置里填写，或读取 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`）。可以按主机配置客户端证书（PEM，或 PKCS#12 加密码），以及系统之外额外信任的 CA，例如公司自己的 CA。
- 桌面版的 multipart 可以在任意行选择本地文件，保存为 `file://` 路径。导入的 `file://` 字段还没有路径时，发送时再选。网页版选的文件只留在这个页面的内存里：同步出去的是一个标记，字节也不会跟着到其他客户端。
- 网页版的请求由服务器发出，只发往公网地址（*0.3.1*）。内网地址会被拒绝，并说明原因。

## GraphQL

- 查询、变量和操作名分开编辑，带语法高亮。POST 以 JSON 发送，GET 以查询参数发送。
- **格式化**会缩进查询（保留注释）和变量。
- 响应里的 `errors` 显示在响应体上方，并在查询中标出所指的位置。
- 获取接口的 Schema 后，编辑查询时会补全字段、参数和枚举值。可以浏览 Schema，点击字段即写进查询。
- 通过 HTTP 发送的订阅，若服务器以事件流返回（GraphQL Yoga、graphql-sse），结果会边收边显示。
- 地址写成 `ws://` 或 `wss://` 时改用 graphql-transport-ws。**订阅**打开连接，每条 `next` 或 `error` 边到边显示，结束时整段记进历史。和 WebSocket 一样只在桌面版可用。经 HTTP 的订阅不变。
- Postman、Insomnia、Hoppscotch、Bruno 里的 GraphQL 请求导入后仍是 GraphQL。

## gRPC

- 一元调用和服务端流。方法选 gRPC，填写 `host:port`，从服务器反射或（桌面版）`.proto` 文件里选择方法。
- 消息用 JSON 编写（可生成示例，也能用模板函数），元数据即请求头。回复以 JSON 显示，并给出调用状态。
- 服务端流的回复边收边显示，每条带到达时间，直到结束或你点击停止。
- 接口会保存它的服务所需的定义，因此在任何地方（包括网页版）发送都不必再向服务器查询。可以复制为 grpcurl。
- 客户端流和双向流只在桌面版连接。**连接**打开调用，**发送消息**发出编辑器里的这条消息，模板每次发送时求值。客户端流点**结束发送**后收那一条回复，双向流边发边收。结束时整段收发记进历史。
- 网页版可以编辑这些方法。运行器、命令行和 AI 助手会跳过。

## WebSocket

- 方法选 WS，填 `ws://` 或 `wss://`（`http(s)://` 按对应的 WebSocket 处理）。**连接**按接口的 Query、请求头、Cookie 和认证（包括 OAuth 2.0 令牌）打开，和普通请求一样走代理、带上该主机的客户端证书。
- **发送消息**（或 ⌘/Ctrl-Enter）发出“消息”标签里的文本，模板每次发送时求值。收发的消息边发边显示，每条带时间。二进制消息以 base64 显示。
- 点**断开**或服务器关闭后，整段对话记进历史。服务器拒绝升级时按普通响应显示。
- 对话最多记 64 MB，和响应体一样。超过时连接被关闭，历史里注明被截断。流式的 gRPC 调用和 GraphQL 订阅也是这样（*0.4.1*）。
- 可以复制为 websocat。目前只在桌面版可用：网页版的服务器不中继 WebSocket，运行器、命令行和 AI 助手会跳过。

## 服务器推送事件（SSE）

事件流（`text/event-stream`）边收边显示：时间、类型、ID 和数据。选中一条显示完整内容，包括它要求的重连间隔。直到服务器结束，或你点击停止。收到的内容存进历史，可以按事件或原始内容查看。适合调试大模型接口的流式回复。

## 变量和函数

- 每个项目有环境变量、自定义变量和全局请求头，可以所有环境共用，也可以按命名环境（dev、staging、prod）分别设置。在项目名旁边切换，只影响你自己。
- 变量弹窗可以一次显示一层，也可以用**矩阵对比**横看“共用”和各环境：未设置的格子会高亮，同名重复变量可以一键归并。
- 编辑者可以把环境标为生产环境（*0.4.1*）。选中时切换器变成红色。发送可能改动数据的请求前先确认：GET、HEAD、OPTIONS 和 GraphQL 查询以外的都要，包括 gRPC 调用和 WebSocket 连接。可以选这个项目到退出前不再询问。运行一个目录或项目前也确认一次。AI 助手在这个环境里只发送不需要确认的请求。
- 目录也可以有自己的变量（*0.4.1*，在目录设置里）。用 `{{value(名称)}}` 读，也可以作地址开头的 `{{名称}}`。近的优先：这次运行的数据和提取的值、接口的路径参数、里层目录、外层目录、当前环境、共用变量。写在这些值里的模板函数不会求值。随环境变化的值仍应写在环境里。
- 行里的锁把变量标为秘密。项目里只留名字。值只属于你：不同步、不导出、不进备份，队友（包括查看者）各填自己的。界面上打码，历史里存的请求也会打码。AI 助手只看得到名字。
- 输入时有提示。`{{g(接口, data.token)}}` 取另一个接口最近一次响应里的字段。还有 `{{value(name)}}`、`{{timestamp()}}`、`{{now(%Y-%m-%d)}}`、`{{uuid()}}`、`{{random(1, 100)}}`、`{{randomString(16)}}`、`{{md5(…)}}`、`{{sha256(…)}}`、`{{hmacSha256(密钥, 数据)}}`、`{{urlEncode(…)}}`。
- *0.4.1* 起还有：`{{now(%Y-%m-%d, -1d)}}`（前移或后移 s / m / h / d / w）、`{{sha1(…)}}`、`{{sha512(…)}}`、`{{hmacSha1(…)}}`、`{{hmacSha512(…)}}`、`{{base64Decode(…)}}`、`{{urlDecode(…)}}`、`{{base64.readFile(…)}}`、`{{readTextFile(…)}}`、`{{openFile()}}`（发送时选择文件）、`{{prompt(说明)}}`（发送时询问，例如一次性验证码，记到应用退出）、`{{env(名称)}}`（本机的环境变量，包括 shell 启动文件里 export 的；桌面版）。

## 响应

- 耗时分为 DNS、TCP、TLS、服务器处理和传输。
- 可查看实际发出的请求。每个请求头标明来源。密钥默认打码。响应头、Cookie 和实际发出的请求头可以按关键字过滤，按行或整表复制。也可以像 `curl -v` 那样看完整报文。
- JSON 可看原始内容、缩进或树形（也支持 NDJSON）。树中节点的菜单可复制值、JSON 或 JSONPath，复制 `{{g(接口, 路径)}}`，或直接加为 JSONPath 断言或运行时的提取。
- 图片直接显示，可适应面板或缩放，并显示格式和尺寸。PDF 用系统查看器打开。HTML 可在浏览器中打开（桌面版）。其他二进制内容以十六进制显示。没有 Content-Type 时按文件头识别。
- 响应体可以复制或保存成文件。可在响应体或原始报文中搜索（状态行的搜索按钮或 ⌘/Ctrl-F，可区分大小写并上下跳转）。JSON 还能用 JSONPath 过滤，按接口记住。
- 每个接口有历史，保留 5–100 条（默认 10），在设置的“数据”里改。每条写明方法和路径。选中一条会把它的请求放回编辑器。可以对比同一接口的两条响应：按行对比响应体，JSON 先缩进，未变的部分折叠。
- 项目的**最近发送**列出所有接口最近的 50 条响应。点一条即打开对应接口并显示它。
- 大响应也不卡。文本响应体和原始报文显示前 1–2 MiB，默认 1，在“数据”里改（*0.3.1*）。超长的一行改为横向滚动。

## 说明、检查和运行

接口的“说明”标签页写它做什么、列出字段（路径参数、Query 和请求头带上类型、是否必填、format 和枚举，*0.4.1*），并保存响应示例。服务器项目的在线接口文档是浏览器里的同一份说明。默认仍要登录。编辑者可以在项目菜单里打开**公开预览…**：知道地址的人就能不登录查看，密钥仍然打码。关掉之后又要登录。项目已经和服务器一致时，开关会马上同步；还有别的未同步修改时，跟下一次同步一起生效。没打开这个开关时，未登录打开会先到登录页，登录后再回到文档。断言对着当前响应边改边查。**运行…**按树的顺序发送一个目录或整个项目，`cyberapi-cli run` 在终端或 CI 里做同样的事。桌面版还可以压测一个接口。

[检查、说明和运行](./CHECKS_zh.md)：字段和 Schema、断言、示例、运行、命令行、压测。

## Cookie

从每个响应中保存，随匹配的请求发送，所有项目共用。可以搜索、新增、修改、删除或全部清空。

## 导入、导出和代码

粘贴 cURL 即新建接口。任何请求都能复制为 cURL、HTTPie、JavaScript `fetch`、Node axios、Python `requests`、PHP Guzzle、Go `net/http`、Rust reqwest、Java 或 C# `HttpClient`、Swift `URLSession`。

可导入 Postman、Insomnia、Hoppscotch、Bruno、Swagger 2 / OpenAPI 3、HAR、`.http` 文件和 cURL。重新导入时默认更新已有的接口，并保留你填写的值。项目或目录可以记住来源地址，以后再同步。

[导入与导出](./IMPORT_zh.md)：格式、更新时保留什么、导出。[从来源同步](./SOURCE_zh.md)：绑定的文档，包括定时同步——跟文档走，参数值和密钥留下。

## Mock 服务

- 桌面版的**Mock 服务…**在本机按接口的示例应答（默认端口 4010，可改）。
- 服务器项目同时在 bridge 的 `/v1/mock/<project-id>/…` 提供地址，显示在同一个弹窗里。用登录会话或 MCP 令牌调用（`Authorization: Bearer cat_…`、`X-CyberAPI-Token` 或 `?token=cat_…`）。
- 按方法和路径找接口。路径是地址去掉变量、协议和主机后的部分。`{{id}}`、`:id`、`{id}` 匹配任意一段，固定的段越多越优先。回这个接口的第一个示例，或请求头 `x-mock-example` 点名的那个。没有示例或找不到接口时回 404，并说明原因。
- 任何来源的页面都能调用。项目改了它随之更新。桌面版弹窗列出本机服务收到的请求。

## 数据

桌面版可备份和恢复，格式与之前的 Tauri 版相同。还会每天自动备份一次到数据目录的 `backups`，保留最近 7 份。可在设置的“本地数据”里关掉，或打开那个目录（*0.4.1*）。

## 团队

- 一个程序或一个 Docker 镜像，可放在根路径或子路径下。账号通过邀请创建。项目角色有查看者、编辑者、管理者。项目可以共享给其他账号或团队，也可以移到别的团队。
- 桌面版可以登录同一台服务器。首页列出团队新加的项目。本机项目可以上传上去，响应历史保留。共享项目可以离线编辑，在你选择的时候同步。期间别人也改过时，由你选择保留哪一份。网页上保留自己的修改时，只交上改过的接口，没打开过的留在服务器上。
- 接口和目录可以设为仅本地，不参与这次同步。
- 服务器为每个项目保留最近 50 个版本（每次同步之前的样子）。编辑者在**历史版本…**里恢复。被替换掉的样子也会保留，所以恢复可以撤回。
- 每个版本都能和现在、或和它的下一版对比（*0.4.1*）：新增、删除、改名、移动、改了内容的目录和接口，以及变量和环境的变化。点改过的接口，查看请求哪里不同。
- 服务器配置了 OpenID Connect（*0.4.1*）时，登录页和桌面版提供单点登录。已被邀请、用户名是该人邮箱的账号会在第一次登录时绑定。密码仍然可用。

## AI 助手

网页版和桌面版（本机 `127.0.0.1`）都是 MCP 服务器。Claude Code、Cursor 等客户端用令牌读取项目、接口、变量和响应，敏感值打码。

- 允许发送时，可以发送已保存的接口。接口启用了断言时，这次回答列出每条结果，没通过的写出实际值。这些结果不记入历史（*0.3.1*）。
- 允许修改时，可以在你能编辑的项目里新建和修改接口，不能删除。桌面版的本机项目走本机 MCP，服务器项目走服务器的 MCP 端点。
