# Cyber API 功能说明

桌面版和网页版的全部功能；只有其中一端才有的会写明。返回 [README](../README_zh.md)。

## 原生、快

支持 macOS、Windows、Linux，由 GPUI 在 GPU 上绘制。几千个接口的项目也是立即打开。浅色、深色主题，中文、英文界面，字号和自动换行可调；桌面版窗口在每块屏幕上都按上次离开时的位置打开。

## 项目、目录和接口

按名称或拼音搜索，拖动调整顺序，创建副本、移动到目录、复制接口配置；常用接口可以置顶（⌘/Ctrl-1…9）；打开过的接口在编辑器上方留成标签页，切回来时编辑内容、响应和还在进行的请求都还在，最多 16 个，超出时关掉最久没看的；用标签上的关闭按钮、鼠标中键或 ⌘/Ctrl+W 关闭（右键菜单可关闭其他或全部），Ctrl+Tab / Ctrl+Shift+Tab 切换，下次打开项目时标签页还在。“新建临时请求”（项目菜单或命令面板）另开一个标签，用这个项目的变量和环境，留在你自己的设置里，重启后还在；关掉标签就丢掉。能编辑项目时，“保存到项目…”选一个目录，它才成为那里的接口（*0.3.1*）。首页的项目可以分组。⌘/Ctrl+Enter 发送，⌘/Ctrl+N 新建接口，⌘/Ctrl+F 搜索接口，⌘/Ctrl+L 跳到地址栏，方向键在接口树中移动，Delete 和 ⌘/Ctrl+D 删除、复制选中的条目，快捷键一览列出全部快捷键。在任何页面按 ⌘/Ctrl+K 打开命令面板：查找任意项目里的接口（按名称、目录或方法，也支持拼音）并直接打开，打开项目，切换环境，或执行命令（新建接口、导入、运行、最近发送、设置等）。

## 请求

Query、请求头、认证（Basic、Bearer 令牌、放在请求头或查询参数里的 API Key、Digest（摄像头、路由器等设备常用），以及 OAuth 2.0 的客户端凭据、密码，和桌面版的授权码 + PKCE（发送前先申请令牌；服务器要求时可以一并发送 audience 和 resource；令牌像 Cookie 一样存在你这里，不进项目、不同步、不进备份；过期或接口回答 401 时重新申请，有刷新令牌时先用它；客户端用 Basic 认证头或放在请求体里；*0.3.1*：桌面版点“授权”打开系统浏览器，在 127.0.0.1 上接收回调，端口默认随机、也可以指定，令牌照同样的方式保存；网页版可以保存这套设置，并说明授权只在桌面版进行；运行、命令行和 AI 助手不会打开浏览器，没有令牌时说明先在桌面版授权），值可以用模板函数；可以设在接口上，也可以继承所在目录或项目的），请求体支持 JSON、表单、multipart、XML、纯文本；任何键值列表都能切换成文本批量编辑。目录可以设置请求头，目录里的接口都会带上。在地址栏里写的查询参数会移到 Query 表。可设置超时、HTTP/1.1 或 HTTP/2、是否跟随重定向，需要时可以接受自签名证书；单个接口可以在自己的“设置”标签里另设其中任意几项。桌面版的请求可以经过 HTTP 或 SOCKS5 代理：在设置里填写，或读取环境变量 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`；还可以按主机配置客户端证书（PEM，或 PKCS#12 加密码），以及系统之外额外信任的 CA，例如公司内部的 CA。

## GraphQL

GraphQL 请求体分开编辑查询、变量和操作名，带语法高亮；POST 以 JSON 发送，GET 以查询参数发送，响应里的 `errors` 显示在响应体上方，并在查询中标出所指的位置。“格式化”会缩进查询（保留注释）和变量。获取接口的 Schema 后，编辑查询时会补全字段、参数和枚举值；还能浏览 Schema 里的类型、字段、参数和说明，点击字段即写进查询。通过 HTTP 发送的订阅，若服务器以事件流返回（GraphQL Yoga、graphql-sse），结果会边收边显示。地址写成 `ws://` 或 `wss://` 的 GraphQL 接口改用 graphql-transport-ws 协议订阅：“订阅”打开连接，每条 `next` 或 `error` 边到边显示，结束时整段记进历史。和 WebSocket 一样只在桌面版可用；经 HTTP 的订阅不变。Postman、Insomnia、Hoppscotch、Bruno 里的 GraphQL 请求导入后仍是 GraphQL。

## gRPC

支持一元调用和服务端流：方法选 gRPC，填写服务器地址，从服务器反射或 `.proto` 文件（桌面版）中选择服务的方法。消息用 JSON 编写（可生成示例，也能用模板函数），元数据即请求头；回复以 JSON 显示，并给出调用状态；服务端流的回复边收边显示，每条带到达时间，直到结束或你点击停止。接口会保存它的服务所需的定义，因此在任何地方（包括网页版）发送都不必再向服务器查询。调用可以复制为 grpcurl 命令。客户端流和双向流只在桌面版连接：“连接”打开调用，“发送消息”发出编辑器里的这条消息（模板每次发送时求值）；客户端流点“结束发送”后收那一条回复，双向流边发边收。结束时整段收发记进历史。网页版可以编辑这些方法；运行器、命令行和 AI 助手会跳过。

## WebSocket

方法选 WS，填 `ws://` 或 `wss://` 地址（`http(s)://` 按对应的 WebSocket 处理）：“连接”按接口的 Query、请求头、Cookie 和认证（包括 OAuth 2.0 令牌）打开连接，和普通请求一样走代理、带上该主机的客户端证书。连上后，“发送消息”（或 ⌘/Ctrl+Enter）发出“消息”标签里的文本，模板函数每次发送时求值；收发的消息边发边显示，每条带时间，二进制消息以 base64 显示。点“断开”或服务器关闭后，整段对话记进历史；服务器拒绝升级时按普通响应显示。可以复制为 websocat 命令。目前只在桌面版可用：网页版的服务器不中继 WebSocket；运行器、命令行和 AI 助手会跳过 WebSocket 接口。

## 服务器推送事件（SSE）

事件流（`text/event-stream`）边收边显示：每个事件的时间、类型、ID 和数据，选中一条显示完整内容和它要求的重连间隔；直到服务器结束或你点击停止。收到的内容存进历史，可以按事件或原始内容查看。适合调试大模型接口的流式回复等场景。

## 变量和函数

每个项目有环境变量、自定义变量和全局请求头，可以所有环境共用，也可以按命名环境（dev、staging、prod……）分别设置；在项目名旁边切换环境，只影响你自己。变量可以设为秘密（行里的锁）：它的值只属于你，项目里只留名字，所以不同步、不导出、不进备份，队友（包括查看者）各填自己的值；界面上打码显示，历史里存的请求也会打码；AI 助手只看得到名字。模板函数如 `{{g(接口, data.token)}}`（取另一个接口最近一次响应里的字段）、`{{value(name)}}`、`{{timestamp()}}`、`{{now(%Y-%m-%d)}}`、`{{uuid()}}`、`{{random(1, 100)}}`、`{{randomString(16)}}`、`{{md5(…)}}`、`{{sha256(…)}}`、`{{hmacSha256(密钥, 数据)}}`、`{{urlEncode(…)}}`、`{{base64.readFile(…)}}`、`{{readTextFile(…)}}`、`{{openFile()}}`（发送时选择文件）、`{{prompt(说明)}}`（发送时弹框询问，例如一次性验证码；填过的值会记到应用退出）、`{{env(名称)}}`（本机的环境变量，包括 shell 启动文件里 export 的；桌面版），输入时有提示。

## 响应

耗时分为 DNS、TCP、TLS、服务器处理和传输；可查看实际发出的请求，每个请求头标明来源，密钥默认打码，也可以像 `curl -v` 那样看完整的原始报文；JSON 可看原始内容、美化后的缩进或树形（也支持 NDJSON）；图片直接显示，可适应面板或缩放，并显示格式和尺寸；PDF 用系统查看器打开，HTML 页面可在浏览器中打开（桌面版）；其他二进制内容以十六进制显示；没有 Content-Type 的响应体按文件头识别；响应体可以复制或保存成文件，JSON 响应还能用 JSONPath 过滤（按接口记住）；每个接口有历史记录（保留条数在设置里改，5–100 条，默认 10 条），每条写明方法和路径，选中一条会把它的请求放回编辑器；可以对比同一接口的两条响应（按行对比响应体，JSON 先缩进，未变的部分折叠）；项目的“最近发送”列出所有接口最近的 50 条响应，点一条即打开对应接口并显示它。大响应也不卡：只显示开头部分，超长的一行改为横向滚动。

## 断言

接口的“说明”标签页写它做什么（纯文本，Markdown 原样显示），并保存一些响应作为示例：在历史菜单里把当前显示的响应“存为示例”，在“说明”里点开看响应体；目录的说明写在目录设置里。说明和示例都跟着项目走：团队成员能看到，AI 经 MCP 也能读到，导出 Postman 和 OpenAPI 时带上（说明、保存的响应、响应示例），从 Postman（包括保存的响应）、Insomnia 和 OpenAPI 导入时也会读进来。

不用写脚本就能检查响应：在接口的“断言”标签页里，每一行检查状态码、某个响应头、JSONPath 取到的值、响应体、耗时或大小，可以是等于、包含、匹配正则、存在、大于或小于、类型是。每一行都会对当前显示的响应检查，边改边看结果，失败时写出实际是什么；状态行显示通过了几条，点它就打开这个标签页。AI 助手发送这个接口时，回答里也带上同样的结果，历史不记这些结果（*0.3.1*）。

可以运行一个目录或整个项目（菜单里的“运行…”）：按树的顺序依次发送，每个请求结束就显示它的响应和断言结果，并汇总通过和失败的数量（没有断言的请求，错误状态码算失败）；运行结束后点一条即打开对应接口并显示这条响应。可以给一份数据（带表头的 CSV 或 JSON 对象数组，粘贴，或在桌面版选文件），每行运行一遍，列的值用 `{{value(列名)}}` 读。断言下面的“提取”从响应里取一个值（JSONPath、响应头、状态码等），同一次运行里后面的请求也用 `{{value(名称)}}` 读，例如先登录、再带着 token 调后面的接口。运行中的值只属于这次运行，不写进项目；发出的请求和平时一样记进各接口的历史。同样的运行也可以不开窗口，在终端或 CI 里做：`cyberapi-cli run` 读一个项目文件（CyberAPI 的导出或任何应用能导入的格式），每个请求结束就打印一行，可写出 JUnit XML，有没通过的就以非零退出码结束（见[安装](./INSTALL_zh.md#命令行)）。

## Cookie

从每个响应中保存，随匹配的请求发送，所有项目共用；可以搜索、新增、修改、删除或全部清空。

## cURL 和导入

粘贴 cURL 命令即新建接口，任何请求都能复制为 cURL、HTTPie、JavaScript `fetch`、Node.js axios、Python `requests`、PHP Guzzle、Go `net/http`、Rust reqwest、Java `HttpClient`、C# `HttpClient` 或 Swift `URLSession` 代码（菜单按命令行、脚本语言、编译型语言分组；跟随重定向、不校验证书照设置写出，Digest 认证在库能自己应答时写成它的写法；OAuth 2.0 写当前的令牌，还没有令牌时写一句从哪里取）；可把 Postman、Insomnia、Hoppscotch（单个集合、“全部导出”或环境）、Bruno（`.bru` 请求或环境文件，或 OpenCollection YAML 导出）、Swagger 2 / OpenAPI 3（JSON 或 YAML）、浏览器开发者工具导出的 HAR（其中的接口调用，不含页面加载的图片、脚本和样式，每个主机一个目录）和 cURL 导入到项目里，或在首页直接导入为新项目，认证（Basic、Bearer、API Key、Digest，OAuth 2.0 的客户端凭据、密码和授权码，*0.3.1*）和环境一起带进来（Postman、Hoppscotch 的环境文件，Insomnia 的子环境，OpenCollection 的环境成为命名环境；Bruno 的 `{{process.env.NAME}}` 变成 `{{env(NAME)}}`；OpenAPI 的安全方案成为项目认证、值由你填），内容可以粘贴、选文件，也可以填地址取回（网页版经服务器取，受“请求能发往哪里”限制）；重新导入时可以只添加新的接口（放进同名目录），也可以同时更新项目里已有的接口（方法和路径相同的），它们的认证、断言和设置保留；可按接口、目录或项目导出，目录和项目还能导出为 Postman 集合（v2.1）或 OpenAPI 3（YAML，地址前缀变量成为 servers，请求体带示例和推断出的 schema，认证只写类型、不写值；OAuth 2.0 写授权方式、令牌地址和范围，授权码另写授权地址和本机回调，*0.3.1*）。

## Mock 服务

桌面版可以让项目按接口的示例充当 Mock 服务：项目菜单里的 **Mock 服务…** 在本机启动它（默认端口 4010，可改）。请求按方法和路径找接口——路径是地址去掉变量、协议和主机后的部分，`{{id}}`、`:id`、`{id}` 匹配任意一段，固定的段越多越优先——回这个接口的第一个示例，或请求头 `x-mock-example` 点名的那个；没有示例或找不到接口时回 404 并说明原因。任何来源的页面都能调用（会回应 CORS 预检），项目改了它随之更新，弹窗里列出收到的请求。项目开着时运行。

## 数据

桌面版可备份和恢复，格式与之前的 Tauri 版相同。

## 团队

可自行部署的网页版：一个程序或一个 Docker 镜像，可放在根路径或子路径下；账号通过邀请创建，有团队和项目级的角色（查看者、编辑者、管理者），项目可以共享给其他账号或团队，也可以移到别的团队。桌面版可以登录同一台服务器，首页随时列出团队新加的项目，也可以把本机的项目上传上去（响应历史等都保留），离线编辑共享项目，在你选择的时候同步；期间别人也改过时，由你选择保留哪一份；接口和目录也可以设为仅本地，不参与同步。服务器为每个项目保留最近 50 个版本（每次同步之前的样子），编辑者可以在项目菜单的“历史版本…”里恢复；被替换掉的样子也会保留，所以恢复可以撤回。

## AI 助手

网页版同时是 MCP 服务器：Claude Code、Cursor 等 MCP 客户端用你签发的令牌读取项目、接口、变量和响应，敏感值打码；允许发送的令牌还能发送已保存的接口；接口启用了断言时，这次回答列出每条的结果，没通过的写出实际值，这些结果不记入历史（*0.3.1*）。允许修改的令牌还能在你能编辑的项目里新建和修改接口（不能删除）。
